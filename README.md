# Mój semestr MKB

Strona do ogarniania studiów na kierunku **Media i komunikacja w biznesie** (WSB Merito, zima 2026/27):
przedmioty i prace zaliczeniowe z Moodle, plan nauki z minutnikiem, test A/B/C, fiszki z inteligentnymi powtórkami i gry.

- `index.html` – cała strona (jeden plik)
- `data.json` – dane startowe: przedmioty, zadania, plan nauki i fiszki

Postęp (odhaczone zadania, wyniki testów) zapisuje się w przeglądarce, w której korzystasz ze strony.
